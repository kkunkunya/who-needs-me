# ADR-0008: 引入猫作为品牌角色，推翻 ADR-0004 的"不做拟人化吉祥物"条款

- status: accepted
- date: 2026-07-15

## 背景

ADR-0004 定 V1 呈现"不做拟人化吉祥物，保持克制工具感"，理由是拟人化与"沉默 hook / 宁缺毋滥"的克制哲学有张力，且市场里跑出规模的项目都是纯功能 UI；`docs/research/2026-07-15-competitor-agent-island.md` 也把"去拟人化"列为 WhoNeedsMe 的一个**次要**审美区隔点。

2026-07-15 建立 `DESIGN.md` 时，用户提供并认可了一张暗色参考图（`docs/design/reference-panel-dark.png`），其中包含一只猫（菜单栏猫脸图标 + 趴着的猫插画）。用户明确选择"推翻 ADR-0004、正式引入猫吉祥物"，并要求"更有存在感，但重点仍是 who needs me"。

## 决策

- **撤销 ADR-0004 中"不做拟人化吉祥物"这一条款**；ADR-0004 的其余决策——不做灵动岛/顶栏、托盘 + Alert、精确只读边界——不变，仍有效。
- **正式引入猫作为 WhoNeedsMe 的品牌角色**，具体规格由 `DESIGN.md` 拥有并约束：
  - 猫有一组表情/姿态**镜像聚合状态**：全静=蜷睡（calm）· 有会话在跑=坐姿警觉（working）· ≥1 个等你=竖耳+看向你+amber（attention）。
  - 猫登台于 Tray Icon、Alert Card、空态、面板 header，**可以有存在感**；但**不进数据行**，且**会话列表 + Needs-You 语义永远是视觉主角**——猫是主持人不是主角。
  - 为与克制哲学共存：猫**保持单色线条**（非彩色卡通），且**只在 needs-you/attention 态用 amber**，与 `DESIGN.md` "强调色只服务 Needs-You"不变量一致。

## 理由

- 用户是决策负责人，明确要角色化带来的温度与辨识度；认可的参考图已把"猫 + 克制暗色工具风"证明为可共存的组合。
- ADR-0004 排斥吉祥物的核心担忧是"花哨 / 角色叙事盖过克制工具感"。本决策用四条边界把这个担忧化解——不进数据行、单色线条、强调色只服务 Needs-You、列表永远是主角——引入的是"有约束的门面角色"，不是无节制卡通。
- 竞品层面：Agent Island 的拟人化是"刘海剧场 + 岛民段位 / 热力图"式社交玩法；WhoNeedsMe 的猫是克制线条门面，二者不是同一种拟人化，不构成"变成 me-too"的风险。且"去拟人化"本就是竞品拆解里判定的**次要**审美区隔（真正护城河是语义化 Needs-You + 严格只读，见 ADR-0006），用它换品牌温度是可接受的权衡。
- 被否备选：维持 ADR-0004 完全无吉祥物（被否——用户明确要温度，且约束足够让猫不破坏克制）；引入无约束的彩色卡通吉祥物（被否——会真正盖过功能主角、与克制哲学冲突）。

## 后果

- ADR-0004 的"不做拟人化吉祥物"条款标记为被本 ADR 取代；其"不做灵动岛/顶栏""只读边界"等其余决策不受影响。
- 猫的形态、状态映射、出现位置由 `DESIGN.md`（accepted）约束，实现须遵守"不进数据行 / 单色线条 / amber 只服务 Needs-You / 列表为主角"四条边界。
- 参考图里"睡猫配 2 个在等你"的语义错位（猫态与聚合态不一致）在实现时须修正。
- memory `whoneedsme-differentiation-2026-07-15` 里"去拟人化是差异化"的旧倾向相应弱化——那是次要审美点，已让位于品牌温度；核心差异化仍是语义化 Needs-You + 严格只读。
- 猫作为主要视觉资产，其绘制/状态集需求进入 DESIGN.md 的验证矩阵（Tray calm/working/attention、Alert 反应态、空态插画）。
